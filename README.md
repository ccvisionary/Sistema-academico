# Sistema académico

Aplicación desarrollada con React y Vite para registrar estudiantes y sus notas. Incluye validación de datos, eliminación de registros y un contador derivado de estudiantes aprobados (nota igual o superior a 3.0).

## Requisitos

- Node.js y npm

## Uso local

```powershell
npm.cmd install
npm.cmd run dev
```

Para generar la compilación de producción:

```powershell
npm.cmd run build
```
